# Task 1: Scan Local Network for Open Ports
Objective: Learn to find open ports to understand network exposure.
Tools Used: Nmap (online), Wireshark concept

Steps I Followed:
1. Found local IP range: 192.168.1.0/24
2. Used Nmap command: nmap -sS 192.168.1.0/24
3. Scanned router IP for open ports
4. Identified risks: Open ports can be entry for hackers
5. Saved results as txt

Outcome: Learned basic network reconnaissance
